Add a browser-safe deterministic JSON reporter with an explicit awaited writer and an additive `@velocious/testing/reporters` export. The Node CLI now selects `default` or `json` output through `--reporter`; completed JSON runs emit only the existing compact result on reserved stdout, retain existing exit semantics, and route all other stdout stream writes to stderr for the remaining process lifetime, including separate consoles, unawaited work, and `beforeExit`-scheduled work. Startup failures are reported immediately even when imported code retains persistent handles, without changing protocol, result, or event shapes.
