Add a browser-safe deterministic JSON reporter with an explicit awaited writer and an additive `@velocious/testing/reporters` export. The Node CLI now selects `default` or `json` output through `--reporter`; completed JSON runs emit only the existing compact result on stdout, retain existing exit semantics, and own console routing to stderr for the remaining process lifetime, including unawaited and `beforeExit`-scheduled work, without changing protocol, result, or event shapes.
