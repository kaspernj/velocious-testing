# Added

- Initial independent `@velocious/testing` package with browser-safe DSL and matchers, explicit reusable or isolated test contexts, a generic runner kernel, Node discovery/CLI support, generated declarations, resolvable shipped source maps, and standalone packaging.
- Installed CLI path-and-line selection uses test declaration locations, and teardown failures are aggregated only after every reverse-order cleanup hook has run.
- Falsy thrown values remain failures across test and hook execution, matcher negation follows the shared assertion contract, and stateful regular expressions are evaluated without mutating caller state.
- TensorBuzz fans a lockfile-only setup into pinned Node 20/22/24 test lanes and one consolidated quality/package lane; GitHub Actions are intentionally absent.
